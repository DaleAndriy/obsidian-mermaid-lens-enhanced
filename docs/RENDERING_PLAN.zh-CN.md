# Mermaid Lens Enhanced 渲染增强：当前方案与验收

更新日期：2026-11-03。

## 产品目标

- 直接处理所有普通 Mermaid 图块，无需改写现有笔记。唯一围栏语言为 `mermaid`。
- 对所有 flowchart / graph 做统一增强，其他图种只轻调字体和配色。
- 保留 Obsidian 原生支持的图种和语法；不将第三方渲染器的语法覆盖范围当作兼容上限。
- 不对《债务危机》或任何节点名称编写专门规则。

## 已实现的接入方式

标准围栏是 `mermaid`，插件的主渲染器是 beautiful-mermaid。这两件事独立：笔记语法不变，不需要 mermaid-enhanced 标记。

插件包装 Obsidian 的 Mermaid render 调用，直接返回 beautiful-mermaid 生成的 SVG；普通流程图不会调用原生渲染器。beautiful-mermaid 使用自己的 ELK 布局，保留长 TD 图横向展开及侧边接入的行为。判断框在布局前按矩形测量，不再事后缩小菱形并移动端点。

渲染器支持的时序图、状态图、类图、ER 图和 XY 图也采用 beautiful-mermaid。尚未支持的图种（例如饼图）、链接和高级语法使用原文兼容回退，避免图表消失或丢失链接。兼容回退使用原生 Mermaid，不是流程图的主渲染路径。

配置管理仍通过 Obsidian 的共享 Mermaid 实例为兼容路径应用全局字体和配色。卸载插件会恢复 render 包装和原有配置。统一复用现有 Viewer、JPG 复制与 SVG ID 隔离。

## 连线路由

对无分组、矩形节点的流程图，在原始布局上统一分配进线与出线连接位置；有畅通通道时对齐端点，避免细小偏移导致多余转折。正交路由同时考虑节点避让、转折长度、交叉、重叠和线间距，优先确定短连接，再为长回路寻找空闲通道。复杂或不适用的布局保留库的几何结果。

## 样式口径

- 流程图：浅蓝普通节点、圆角；判断节点用更浅填充与虚线外框；标签用浅底胶囊并加粗，盖住连线。
- 容器：白底与浅灰外框、深色标题，让外框和浅蓝节点有明确差别。
- 其他图种：统一中文字体栈及协调配色，保留原生形状与布局。饼图在兼容路径采用蓝、绿、橙、黄等可区分颜色。
- Viewer：纯白背景；复制完整图表，不带当前平移和缩放变换。
- 配置：保留草稿、应用、保存失败回滚语义；已有用户 JSON 不擅自覆盖，新主题可通过恢复默认配置采用。

## 验收

1. 使用 01 至 04 页普通 Mermaid 样例检查阅读视图与实时预览。
2. 检查简单 LR、复杂 TD、循环反馈、嵌套 subgraph、classDef、样式、链接、中文和重复 SVG ID。
3. 确认饼图、时序图、状态图、类图、ER 图继续正常显示。
4. 检查判断框尺寸、连线边界、标签遮线、分组层次、字体、长中文。
5. 检查 Viewer 所有交互、复制的完整性与留白。
6. 禁用再启用插件，确认原生渲染与增强均可恢复，没有重复绑定。

自动化检查涵盖源文保护、其他图种直通、原生失败回退、卸载恢复，以及原项目的配置和 Viewer 行为。复杂 TD 反馈环已在 Obsidian 测试 Vault 的查看器中检查；发布前仍应按上面的清单验证受影响功能。
